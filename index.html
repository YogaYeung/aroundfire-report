这份调研的取数纪律

数据边界声明（各页均原样保留，未因排版删改）
  • 抓不到的一律标"未取得 / 未查证"，不估、不猜。例：Solo Stove 官网 PDP 返回 403，重量未取得；Gather Grills 三款重量官网未列；AroundFire 桌面承重全站未见（是"站上没写"，不是"产品没有"）。
  • 采样非全量的地方标注覆盖度。Meta Ad Library 主页视图有渲染上限：AroundFire / NOMAD / BioLite / KBBQ Bros 为 100% 全量，Solo Stove ~52%、Breeo ~49% 为代表性采样，比例结论不外推成全账户精确占比。
  • 被平台拦截的如实列出。Amazon 1–3 星差评全文页三条路径全部跳登录墙（已改用 Amazon 官方「Customers say」属性级负面统计替代）；reddit.com 对本机出口 IP 全面 403（改用公开归档 API，每条附 permalink）；Walmart / Home Depot / REI / Wayfair 机器人验证拦截，零数据；Instagram 对本机 IP 强限流，9 个账号只截到 6 张主页网格。
  • 口径与任务书不一致的地方以实际处理结果为准并写明。关键词表实为 218 个有效词（非 240，原表含 7 行重复表头）；KBBQ 词群 21,650/月（非 43,300，后者疑为重复计数）；达人台账实为 33 行（非 998 行）。
  • 假设与事实分开。定价模型里凡标「假设」的数字（出厂价 $60、3PL 追加成本 $23/件、Lite:Grande = 70:30 等）均未经验证，是为让测算可推演而设的参数，拿到甲方真实数据后需回填重算。
  • 预期影响一律不量化成百分比——没有对照实验支撑的转化率提升数字都是编的。
  • 网站方案未在目标站注入任何 CSS / 选择器（只读实勘），后台路径为 Shopify 通用路径，落地时需登录甲方后台逐条实测。
