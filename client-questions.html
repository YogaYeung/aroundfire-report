甲方会议 · 待确认问题清单

开会直接照着念的一份清单：27 个待甲方确认的问题，分 6 个板块。每条固定三段——① 直接能念的问题原话 ② 为什么要问 / 不确认卡住哪一步 ③ 希望甲方给的答案形式。全部来自本次调研的真实发现，服务后续网站优化 / Meta 广告 / 社媒发帖三条线。

📅 2026-07-22🗒️ 27 个问题 · 6 个板块🖨️ 可打印 · 可现场勾选
怎么用这份清单 按板块问，🚨 最优先的先问。板块 0 里的 3 个问题是地基——出厂成本、履约模式、量产版有没有修好，它们同时卡住网站、广告、定价好几条线，甲方一确认，后面很多问题就顺了。每个问题左边有方框，甲方现场答完就勾掉；答案先记在页面最底部的「会议记录区」表格里。看不懂的英文缩写点下面的「术语速查」。
术语速查 · 看不懂的英文缩写点这里
FOB / 出厂价
工厂交货价，货在工厂装船那一刻的成本价，不含运费和关税。算毛利的起点。
SKU
一个独立的商品 / 规格（Lite、Grande、燃气版算三个不同 SKU）。
3PL / 美国仓
第三方海外仓 + 代发货，货先备到美国仓，客户下单就近发。
de minimis
美国原本 800 美元以下小额包裹免征关税的额度，现已取消，中国直发要按售价补缴关税。
load capacity / 承重
桌面能压多少重量而不塌不晃，通常标磅（lbs）或公斤。
3-in-1 / 4-in-1
「一物几用」的卖点说法，指这张桌子能当几种东西用（烧烤炉 / 火盆 / 桌子……）。
BTU
火力单位，数字越大火越猛、烤得越快。
KBBQ
韩式烤肉（Korean BBQ）。
less smoke / smokeless
少烟 / 无烟设计，靠双层壁二次燃烧把烟再点着，少冒烟。
ROAS
广告支出回报率。花 1 元广告费换回几元销售额，一般 3 以上算健康。
像素 / CAPI
Meta 追踪转化的两条数据回传通道，配全了广告才知道谁下了单、才能优化和放量。
UGC
用户 / 达人自己拍的真实使用内容，区别于品牌自制精修广告。
达人 / 素材授权
拿到达人拍的内容后，能不能继续投广告、能不能二次剪辑使用的书面许可。
落地页
广告点进去后到达的那一个售卖页面。
BNPL
先买后付 / 分期付款（如 Shop Pay Installments、Klarna），下单先拿货、分几期还。
handle
社媒账号的用户名，@ 后面那串（如 @aroundfireoffical）。
免邮门槛
订单金额满多少就免运费的那条线（如「满 $199 免邮」）。
lbs（磅）
重量单位，1 lbs ≈ 0.45 公斤。
$（美元）
本清单按 1 美元 ≈ 7.2 元人民币换算。

🚨 板块 0 · 最优先：卡住多条线的地基问题

3 个问题 这 3 条一天不确认，网站毛利、广告能不能放量、燃气套装能不能上，全都只能用假设值推。开会先问这三个。
Q1🚨 最优先

每个 SKU 的出厂价 / FOB 成本（工厂交货价）是多少？

① 问题Gather Lite、Gather Grande、燃气版这三款，工厂给你们的出厂价分别是多少？

② 为什么问免邮门槛测算、关税测算、毛利核算三件事全靠它。现在定价模型里出厂价用的是假设值 $60，拿不到真实成本，所有钱的账都是虚的、结论不能落地。

③ 希望甲方给三款各一个数（每台出厂价）。

Q2🚨 最优先

现在是中国仓直发，还是有美国仓（3PL）？有没有转美国仓的计划？

① 问题目前订单是从中国仓直接发给美国客户，还是货已经备到了美国仓？未来有没有打算上美国仓？

② 为什么问美国 de minimis（$800 小额免税额）已取消，中国直发要按售价补关税，每件多缴 $27–94，燃气套装直发是卖一台亏一台。是否转 3PL，直接决定后面免邮门槛、能不能上 Amazon、燃气套装能不能成立——好几条线都挂在这个答案上。

③ 希望甲方给当前履约模式（直发 / 美国仓）+ 是否愿意上美国仓（是 / 否 / 在评估）。

Q3🚨 最优先

量产版有没有修掉众筹时暴露的 4 个问题？

① 问题Kickstarter 众筹时用户反馈的这 4 个问题，量产版逐条改了没：①桌子太矮（后来加了 70cm 加高腿）②火网寿命（官方说"至少 50 次"）③风屏要拧螺丝装 ④火网漏油（烤肉的油会漏到地上）？

② 为什么问这 4 个直接决定网站卖点能不能写——没修好还照写，会变成退货和差评。改没改、改到什么程度，得逐条落实才能定详情页怎么讲。

③ 希望甲方给4 条逐条回复：修了 / 没修 / 改善到什么程度。

🌐 板块 1 · 网站优化相关

7 个问题 规格表里多处写着「待确认」，还有几处全站自相矛盾——这些不定下来，详情页没法上线、卖点没法写。
Q4⚠️ 重要

桌面承重（load capacity，能压多少斤）到底是多少？

① 问题这张桌子桌面能承受多少重量？给个官方数值。

② 为什么问规格表里现在写的是 [to be confirmed]（待确认）。用户评价里，"稳、靠着切菜不晃"比"轻"更是买点，可现在没数值就写不了这个卖点。

③ 希望甲方给一个数（磅或公斤）。

Q5🚨 最优先

Gather Grande 到底能坐几个人？（全站现在自相矛盾）

① 问题Grande 官方标准的可坐人数是几人？

② 为什么问这是信息事故：导航写「Seats 6-8」，产品页 FAQ 却写「8-10」，全站自己打自己。$239 的产品，"能坐几人"是用户下单的核心依据，两个数并存会让人当场不信任。

③ 希望甲方给一个准确区间（定死一个口径）。

Q6⚠️ 重要

产品到底是 3-in-1 还是 4-in-1？（全站两个口径并存）

① 问题对外统一说 3-in-1 还是 4-in-1？定一个。

② 为什么问全站两种说法并存（9 处不一致，还有一张图的文件名把 versatility 拼错成 vesality）。这个数字是核心卖点关键词，一会儿 3 一会儿 4，SEO 关键词和用户认知都被劈成两半。

③ 希望甲方给定一个口径（3-in-1 或 4-in-1）。

Q7🚨 最优先

对比表里的「69 lbs / 55 lbs / 90 lbs」分别是哪个竞品的哪个型号？

① 问题产品页那张 "What makes us different" 对比表里，列的竞品重量 69 / 55 / 90 磅，各是哪个品牌、哪个型号、数据从哪来的？

② 为什么问表里列了竞品重量却没标来源。无来源的竞品对比 = 可被投诉的比较广告（有法律风险）。我们要把它改成能读的 HTML 表之前，必须先核实每个数字的出处，否则不敢上。

③ 希望甲方给每个数字对应的品牌 + 型号 + 数据出处。

Q8⚠️ 重要

火网 / 护盾 / 螺丝坏了，能不能提供免费补件？

① 问题如果客户的火网、风屏护盾或螺丝坏了，我们能不能免费寄配件补给他？有没有这个政策？

② 为什么问这是整个调研里投入产出比最高的一条动作：同结构竞品 Fireside 靠"次日免费补件"把一堆差评救成 5 星。能做的话就写进详情页，是个几乎免费的信任杠杆。

③ 希望甲方给是否能提供（是 / 否）+ 政策细节（保修期、免费范围）。

Q9⚠️ 重要

"less smoke（少烟）"能不能给一段实测条件？

① 问题宣传的"少烟"，是在什么条件下测的——多大火、用什么木柴 / 燃料、烧多久开始起效？能不能给一段实测说明，或者配合我们拍一条？

② 为什么问竞品被骂得最狠的就是"无烟"名不副实（226 条负评里 45% 是这一条）。甲方的措辞（"less smoke"而非"smokeless"）比竞品安全，但要把条件前置说清楚，才不会重蹈覆辙挨骂。

③ 希望甲方给一段实测说明，或愿意配合拍摄（是 / 否）。

Q10⚠️ 重要

其余规格能给一份完整真实数据吗？（现在全是「待确认」）

① 问题整机尺寸、收纳后尺寸、材质、BTU（火力单位）、有没有拿到认证——这些能给一份完整规格表吗？

② 为什么问规格表和落地页里这些字段现在都是 [to be confirmed]（待确认）。上线前必须填真实数据，缺一项详情页就有一块开天窗。

③ 希望甲方给一份完整规格表（尺寸 / 收纳尺寸 / 材质 / BTU / 认证）。

📡 板块 2 · Meta 广告投放相关

7 个问题 账户现在 ROAS 5.69 很健康，但预算规模、放量方向、数据回传、达人资产这几件不定，优化和放量都使不上劲。
Q11🚨 最优先

每月广告预算规模是多少？

① 问题Meta 这边每月能投的预算大概是多少？

② 为什么问预算规模决定能同时跑几组、够不够跑出学习期。数不定，后面所有投放结构都排不了。

③ 希望甲方给月预算数（一个金额 / 一个区间）。

Q12⚠️ 重要

投放目标是"保效率"还是"要放量"？

① 问题接下来的重心，是维持现在这个高回报率稳稳赚，还是加预算冲量、哪怕回报率降一点？

② 为什么问现在账户 ROAS 5.69（很健康）。继续保效率 vs 加预算放量是两套完全不同的打法——出价、素材节奏、人群都不一样，得先定方向。

③ 希望甲方给一个方向（保效率 / 放量 / 两者的平衡点）。

Q13🚨 最优先

Meta 像素 / CAPI（转化回传）有没有配全？

① 问题网站的 Meta 像素和 CAPI 转化回传，现在是怎么配的？谁配的、配全了没？

② 为什么问账户里有 27% 的花费是"零归因结果"（花了钱但系统不知道带来了什么），这很可能是回传断了链。回传不准，优化和放量都会失真——等于蒙着眼投。

③ 希望甲方给像素 + CAPI 的配置状态（谁负责 / 配了哪些事件 / 有没有验证过）。

Q14🚨 最优先

跑赢的 5 个达人素材，联系方式和二次使用授权拿得到吗？

① 问题这 5 位达人（evcinshome / cait / vanadvantures / Paige / betweenus）的联系方式还有没有？他们拍的素材，我们能不能继续投、能不能二次剪辑使用？

② 为什么问这 5 条素材 ROAS 均值 >5.5、合计已经花了 $7,021，是已经验证过的确定性资产。但达人库里一条联系方式都没记，拿不到人就没法复投、没法找他们复购新素材——等于白白丢了已经跑通的钱。

③ 希望甲方给这 5 位的联系方式 + 素材是否可继续投放 / 二次使用（是 / 否）。

Q15⚠️ 重要

要不要开 KBBQ（韩式烤肉）这个方向？

① 问题KBBQ 这个方向，我们做不做？要做的话就单独铺素材和落地页。

② 为什么问KBBQ 有 43,300 搜索量、目前零投放，配件（KBBQ 烤盘）产品线已经有了——是账户里最大的未开发方向。但要甲方点头，我们才好投人力铺素材和落地页。

③ 希望甲方给做 / 不做。

Q16⏳ 一般

燃气版落地页做不做？做了广告能不能配合开？

① 问题燃气版的独立落地页要不要上线？上线的话，广告端能不能配合开（做禁火州定向 + 6-8 月旺季投放）？

② 为什么问燃气版落地页设计稿已经做好了（禁火令期间可合法用是它的核心卖点），但要甲方决定上不上；上了之后广告端才好配合开定向。

③ 希望甲方给是否上线（是 / 否）+ 广告配合意愿。

Q17⏳ 一般

现有素材的原始文件（视频源）能给吗？

① 问题现在在投的这些广告视频，有没有原始源文件？能不能给我们素材库的访问权？

② 为什么问账户现在 100% 是视频、零静态图，钩子只有"多功能 / 便携"两个角度。要做价格促销、对比、痛点、证言等新角度素材，有源文件就能二次剪，效率高很多。

③ 希望甲方给素材库访问权 / 视频源文件。

📱 板块 3 · 社媒发帖相关

5 个问题 要发帖，先得拿到账号权限、有真实场景素材、定好谁来发。这几件不落实，社媒这条线动不起来。
Q18🚨 最优先

官方社媒账号谁在管、权限给谁？（TikTok / IG / YouTube）

① 问题TikTok、Instagram、YouTube 三个官方号现在谁在管？能不能把发帖权限给到我们？另外：TikTok 的账号名是 @aroundfireoffical（官网页脚拼错了，official 少个 i），YouTube 停更 16 个月了，这两个要不要处理？

② 为什么问要发帖，第一步就是拿到账号权限，没权限一步都动不了。handle 拼错和长期停更也会影响品牌观感，顺便一起定了。

③ 希望甲方给三个平台的账号权限 + handle 要不要改（是 / 否）。

Q19⚠️ 重要

有没有产品实拍 / 真人围坐场景素材库？UGC 授权拿得到吗？

① 问题有没有产品实拍图、真人围坐一起用的生活场景素材库？用户自发拍的内容（UGC），能不能拿到授权用于官方发布？

② 为什么问调研里 38 条爆款帖没有一张白底产品图，真正能打的都是"人的关系"场景。要持续发帖，得有源源不断的真实场景素材撑着。

③ 希望甲方给素材库访问权 + UGC 授权情况（有 / 没有 / 能不能拿到）。

Q20⚠️ 重要

发帖谁执行、什么节奏？

① 问题接下来社媒发帖由谁来执行？目标是每周发几条？

② 为什么问现在 IG 只有 0.29 条/周，头部品牌是 6.36 条/周，差了 22 倍——发帖量是最大短板。得先定谁来发、发多频，量才能提上来。

③ 希望甲方给执行人 + 目标发帖频率。

Q21⏳ 一般

抽奖联名能不能协调到其他品牌？

① 问题做联名抽奖（要求参与者"关注 N 个账号"那种），甲方手上有没有能一起玩的合作品牌？

② 为什么问调研发现抽奖是这个品类涨评论、涨粉唯一有效的杠杆，而且必须是"关注 N 个账号"的联名形式才有放大效果。这需要甲方去谈合作品牌，我们谈不了。

③ 希望甲方给有没有可联名的伙伴品牌（有 / 没有 / 去谈）。

Q22⏳ 一般

KBBQ / 围炉共烤的内容方向，甲方认不认？

① 问题社媒内容主打"KBBQ / 一群人围着炉子一起烤"这个方向，甲方认可吗？

② 为什么问这是甲方产品结构天然占住的差异点（别家做不到围坐共烤）。但内容方向要甲方拍板认下来，我们才好持续产出，不然做一半又改方向。

③ 希望甲方给认可 / 不认可。

💰 板块 4 · 定价 / 履约 / 成本（会影响以上所有）

5 个问题 这一块牵一发动全身：免邮、分期、补货、燃气套装、澳洲时效，任何一条定错都直接吃转化或踩合规。
Q23⚠️ 重要

免邮门槛设多少能接受？

① 问题免邮门槛你们能接受设到多少？（现在是运费 $24.90、没有免邮门槛；竞品普遍满 $199 / $200 免邮，或干脆全免。）

② 为什么问要设门槛得先有出厂成本才能算毛利（见 Q1），也需要甲方定策略。现在无门槛收 $24.90 运费，是结账流失的一大原因。

③ 希望甲方给能接受的门槛价；或者说"你们基于成本算完再来定"。

Q24⏳ 一般

要不要接 BNPL（先买后付分期）？

① 问题要不要接分期付款（Shop Pay Installments / Klarna 这类）？

② 为什么问$189–239 正好是分期最能提转化的价格带，现在全站零分期。接入只是 Shopify 后台配置，不用开发，几乎零成本。

③ 希望甲方给接 / 不接。

Q25⏳ 一般

Cast Iron Griddle（$69 铸铁煎盘配件）什么时候补货？

① 问题$69 的铸铁煎盘配件现在缺货，什么时候能补上？

② 为什么问这是目录里最高价的配件，缺货 = 0 转化，纯白白损失的机会成本。补上就能卖。

③ 希望甲方给补货时间。

Q26⚠️ 重要

燃气套装（$259 / $349）现在直发是亏的，要不要单独定价或只走美国仓？

① 问题燃气套装这两个 SKU，要不要单独调价，或者规定只从美国仓发？

② 为什么问在中国直发模式下，这个 SKU 因为关税卖一台亏一台（关税占售价一大半）。不定策略就会一直流血。（和 Q2 履约模式连在一起看。）

③ 希望甲方给定价 / 履约策略（单独定价 / 只走美国仓 / 暂时下架）。

Q27⚠️ 重要

澳洲发货到底几天？（政策页和结账页自相矛盾）

① 问题发到澳洲真实要几天？政策页写的是 8-10 天，但结账页实测显示 25-30 天，哪个是真的？

② 为什么问两个口径打架，而且时效虚假陈述有合规风险——澳洲消费者法（ACL）有过罚 2500 万澳元的案例。必须统一成真实时效。

③ 希望甲方给真实发货时效（一个数），并统一全站口径。
