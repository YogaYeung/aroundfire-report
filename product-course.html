先记住这一句 · 全课都挂在它上面

AroundFire = 一张能折叠的桌子 ＋ 一摞配件，每个配件解锁一种新吃法；而钛合金桌面板是枢纽——装了它才能上燃气炉。

把这句话背下来。后面所有产品——两张桌子、九个配件、三档高度、四种吃法——都只是在给这句话加细节。只要记得「桌子是底座、配件解锁吃法、钛桌面板是那把总钥匙」，就不会乱。

① 一张桌子（底座）
30 秒展开的双折叠桌，中间是一张不锈钢火网，能直接生火。Lite 或 Grande 二选一。

盖住火网变平桌 + 当挡风板 + 燃气炉的安装底座。想上燃气炉，必须先有它。

燃气炉、韩烤网、铁板、火锅锅、加高腿、灯架……每个配件解锁一种新玩法。

LEVEL 1

大局观：这到底是个啥

小测 0/2
学完你会一句话说清 AroundFire 卖的是什么——知道它同时能当烧烤炉 / 火盆 / 聚会桌，核心是「能折叠 + 会生火 + 可加配件」，而不是一件单一功能的产品。

AroundFire 官方叫它 3-in-1 便携户外桌（一物三用：grill 烧烤炉 ＋ fire pit 火盆 ＋ 聚会桌）。它最大的特点是 patented dual-fold design 专利双折叠结构 ＋ ultralight fire mesh 超轻火网，官方主张这是「最便携的一体式露营桌」，30 秒就能展开。一张桌子，既能围坐吃饭，中间那张火网又能直接烧炭火 / 柴火办烧烤和篝火，还能加配件切换成燃气灶或火锅。用在露营，也用在自家后院。

为什么它不是「一件普通烧烤炉」 普通烧烤炉只能烤。AroundFire 卖的是「一张底座 + 一套可换配件」的系统：底座负责折叠、便携、生火；配件负责把它变成你当下想要的那种工具。理解这一点，你就抓住了整门课的骨架——后面所有内容都是在解释「有哪些底座」和「有哪些配件、各解锁什么」。
🧠 讲给朋友听试着不看屏幕说出「3-in-1 指哪三样」。（答案：烧烤炉 grill、火盆 fire pit、聚会桌。）

两套系统：高度系统 ＋ 燃料 / 吃法系统

🪜 高度系统：一张桌子 3 个高度，对应 3 种坐姿

同一张桌子能调 3 个高度（最高那档要装加高腿）。高度不只是舒适度，它切换的是这张桌子此刻的「身份」：

38cm
15'' · 火盆模式
最低档，取暖效率最好——大家围低桌烤火取暖。
55cm
21.6'' · 露营椅高度
中间档，配露营矮椅刚好，烧烤 / 聚会常用高度。
70cm
27.5'' · 餐桌高度
需装加高腿解锁。普通餐桌高度，配餐椅在后院正经吃饭更舒服。

记法：越低越像火盆（取暖），越高越像餐桌（吃饭）。38 / 55 基础高度自带，70 要加高腿。

🔥 燃料 / 吃法系统：一张火网，4 种玩法

桌子中间那张火网是「万能底」，配不同东西就切换成不同吃法：

① 火网上直接烧（明火）

炭火 / 柴火 / 颗粒直接放火网上烧，用来烧烤 ＋ 篝火取暖。这是最原始的玩法，不用任何配件。

② 换「烹饪面」（韩烤网 / 铁板煎盘）

把韩式烤网或铸铁煎盘放到火网上，换一种做饭方式（围坐韩烤 / 铁板煎牛排早餐）。

③ 燃气灶（钛桌面板 ＋ 燃气炉）

装上钛桌面板 ＋ 燃气炉，变成燃气灶（丁烷 / 丙烷可切换），煮咖啡炖汤炒菜。⚠️ 记得：先有钛桌面板才行。

④ 火锅（铝箔火锅锅）

把铝箔火锅锅放桌子中间，围炉吃火锅（双格能鸳鸯锅）。

🚫 安全红线（官方明确） 火网不可用液体燃料（也不可用变色剂）。这是官方对火网的明确限制，对外讲解 / 写文案时不能违背。
🧠 讲给朋友听把「38 / 55 / 70cm 分别像什么」和「4 种吃法怎么切换」各复述一遍。卡在哪档，就回头再看哪段。

正确答案 A。越低越像火盆、取暖越好；越高越像餐桌、越适合吃饭。

Q3.关于火网的燃料，下面哪条是官方明确禁止的？

正确答案 C。炭 / 柴 / 颗粒都可以，火锅锅也行，唯独液体燃料和变色剂被官方明确禁止。

场景 1

一对小夫妻，预算有限，常开车去露营，就俩人偶尔带个朋友。主要想烧烤 + 晚上围着火取暖，不做复杂菜。

想想：需要大桌吗？需要燃气炉吗？需要加高腿吗？

推荐：Gather Lite · Basic 基础版（$189），不加配件。

为什么：人少、预算有限、常搬运 → 选更小更便宜的 Lite。只烧烤 + 取暖，用火网直接烧炭 / 柴即可，不需要钛桌面板和燃气炉。高度用自带的 38cm（取暖）/ 55cm（露营椅）就够，不必加高腿。一台基础版正中需求。

场景 2

一位露营咖啡爱好者，喜欢在营地慢慢煮咖啡、炖点汤、煎蛋，还想坐得舒服些（配自带的露营餐椅），就一个人到两个人用。

想想：想「像家里一样开火做饭」＝ 需要什么枢纽配件？坐得舒服 ＝ 需要哪档高度？

推荐：Gather Lite · 全配（钛桌面板 ＋ 加高腿 ＋ 1 个燃气炉，$269）。

为什么：想煮咖啡 / 炖汤 / 煎蛋 = 要燃气灶能力 → 必须配钛桌面板 ＋ 燃气炉（燃气炉离不开钛桌面板这个枢纽）。人少选 Lite（1 个燃气炉够用）。想坐得舒服 → 加加高腿上 70cm 餐桌高度配餐椅。三件配齐正好是 Lite 全配。

场景 3

一群朋友（六七个人）特别爱吃韩式烤肉，喜欢围着炉子边烤边聊，经常在后院聚会。

想想：人多选哪张桌子？「韩式烤肉」要哪个做饭升级配件？

推荐：Gather Grande ＋ KBBQ Style Grill Grate 韩式烤肉烤网（$37）；人多可再加 BBQ 烧烤夹 4 支装（$16）。

为什么：六七个人围坐 → 选更大的 Grande（座位数以甲方确认为准，但相对更大坐得下更多人）。爱吃韩烤 → 配 KBBQ 烤网（小格子网专为围坐韩烤设计）。人多每人一把夹子 → 顺带 4 支装烧烤夹。不需要燃气炉，因为需求是围坐炭烤而非燃气做饭。

场景 4

一个爱下厨的大家庭，聚会时想「两个灶头同时开」——一边煮一锅汤 / 咖啡，一边另一个炉子炒菜煎东西，效率要高。

想想：「同时两个燃气炉」这个硬需求，只有哪张桌子做得到？前提配件是什么？

推荐：Gather Grande ＋ 钛桌面板 ＋ 2 个燃气炉（对应 $349 那档）。

为什么：「同时 2 个燃气炉」是硬门槛——只有 Grande 能上 2 个，Lite 最多 1 个，所以桌子只能选 Grande。要上燃气炉必先有钛桌面板（枢纽）。配齐就是 Grande 带 2 燃气炉那档（$349）。这题考的就是「Lite / Grande 燃气炉上限」这条分水岭。

场景 5

一家人冬天想在后院「围炉吃火锅」，最好还能有点夜晚氛围灯，鸳鸯锅同时两种锅底。已经有一张 Gather Lite 基础版了。

想想：吃火锅要哪个配件？想两种锅底 ＝ 什么设计？氛围灯呢？已有桌子还要买新桌吗？

推荐：在已有的 Lite 上加 铝箔火锅锅 12 个装（$37）＋ 灯架（$33），无需换桌。

为什么：已有桌子够用，不必买新桌——这正是「底座 + 配件」系统的好处，加配件就能解锁新吃法。围炉火锅 → 铝箔火锅锅，它的双格设计刚好满足「鸳鸯锅两种锅底」。夜晚氛围 → 加灯架。火锅锅放火网中间即可，不需要钛桌面板 / 燃气炉。
