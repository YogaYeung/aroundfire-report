3问题清单（按严重度排序）

🚨 P0-1 首屏 3 秒回答不了「凭什么信」——零信任信号，且把最硬的资产扔了

事实（实测）

  • Hero 主标题 Grill, Cook & Stay Warm- All-in-One Outdoor Table：该文本节点 tagName = DIV，fontSize 39.1px，不是 <h1>；文案里 Warm- 后面直接换行，是一个悬挂连字符
  • 首屏 CTA 只有一个：Shop Now，127×50px，background rgb(188,43,43)
  • 首屏内没有任何价格、星级、评价数、媒体背书、Kickstarter 数据
  • 全站文本检索 kickstarter|backer：首页 false、Gather Lite PDP false
  • Hero 背景是视频，源分辨率 882×480（Shopify SD-480p-1.5Mbps），在 1440px 宽视口下拉伸铺满

为什么是 P0：竞品的信任资产密度是 Breeo The Original / Since 2011 / American Made、NOMAD 8,000+ Five Star Reviews + 16 条媒体引语墙、Gather Grills 500+ grills / 50+ country clubs、KBBQ Bros 5,000+ tables sold。AroundFire 首屏是 0。而它手上有 541 backers / $134,789 / 2696% 这个和竞品同量级的数字，一个字都没用。

🚨 P0-2 全站零运费预告，$24.90（约 ¥180）在结账第 4 区块才砸出来

  • PDP 价格下方唯一提示：Shipping calculated at checkout.（无金额、无门槛、无预估）
  • 购物车：Taxes and shipping calculated at checkout
  • 结账页必须填完 Email + 8 个地址字段（含强制手机号），第 4 个区块 Shipping method 才从占位文案变成 Standard (3-7 Business Days) $24.90
  • 无任何免邮门槛：买 2 台（$378，约 ¥2,720）运费仍是 $24.90
  • 运费占 Gather Lite 客单价 13.2%
  • 移动端表现最狠：顶部 Order summary 总价从 $189.00 无预告跳到 $213.90（约 ¥1,540）
  • 全站唯一写着 $24.9 的地方是页脚运费政策页的表格

对照 Meta 账户数据：加购 2,641 → 发起结账 1,380（52.3%，每 100 个加购的人约 52 个走到结账页）→ 购买 457（结账后仅 33.1%，每 100 个到结账页的人只有约 33 个真正付款）。结账→购买流失 67%（每 100 个进结账的人有 67 个没付款就走了），是全链路最大瓶颈。

叠加伤害：零 BNPL（$189–239 正是 BNPL 提升最明显的价位段）、Payment 区块正下方摆 Add tip 打赏模块（10% $18.90 / 15% $28.35 / 20% $37.80，约 ¥136 / ¥204 / ¥272）。

🚨 P0-3 PDP 最强说服模块「What makes us different?」是一张图片，机器和读屏器全读不到

  • PDP 全文 document.body.innerText 中检索 Total Weight → false，69 lbs → false
  • 该模块实为单张图片 VS_e9f2a520-….webp，渲染尺寸 677×611，alt 为空字符串
  • 图片里承载的信息（肉眼可读、DOM 不可读）：Total Weight 16 lbs vs 69 / 55 / 90 lbs；Foldable / Integrated Design / Charcoal Grill / Campfire / Height Adjustable
  • 左侧配的文字只有一段泛泛的 Why carry heavy, complicated gear when one table does it all?
  • 顺带：PDP 卖点长图 4-in-1_vesality.webp / cook_anywhere.webp / fire_mesh_details.webp alt 全部为空；首页 164 张 img 中 56 张空 alt

🚨 P0-4 首页没有 <h1>，标题层级从 H6 起跳

首页 document.querySelectorAll('h1') → 长度 0；h2 → 长度 0。实际标题序列（节选）：H6:Gather Lite Basic Set → H6:Ultra Portable Design → H6:3-in-1 Functionality → H3:Less Hassle. More Fun. → H4:Two Sizes of Tables → H6:AS SEEN IN …

首页 JSON-LD 只有 Organization + WebSite，无 ItemList。

PDP 侧正常：H1:Gather Lite Basic Set、H1:Gather Grande Basic Set；集合页 H1:Grill & Fire Pit Tables。问题只在首页——而首页是品类词（"portable grill table"）主要落地页。

⚠️ P1-6 Gather Grande 的座位数自相矛盾（6-8 还是 8-10？）

位置实测原文
全站导航下拉Gather Grande Basic Set — Seats 6-8 People

（Gather Lite 侧一致，都是 4-6。问题只在 Grande。）对一个客单价 $239、以"能坐下几个人"为核心购买依据的产品，这是直接影响选型决策的信息事故。

⚠️ P1-7 品类第一差评源（耐久 / 稳定）在决策位置完全没有被正面回应

VOC 事实：durability 363 提及 / 228 条负面（63%）；stability + sturdiness 合计 860 提及 / 366 条负面；而 weight 87 提及仅 3 条负面 → "稳"比"轻"重要得多。

站上现状（实测）：买盒 above the fold 0 条规格；16 lbs、Folded Size、Unfolded Size、Grill Size、304 stainless steel 全部埋在默认收起的 Specifications 折叠块；火网寿命 guaranteed to last at least 50 uses or one year 只出现在 FAQ 第 7 条（页面 y≈9,400px）；全站检索 Dimension = 0 次、Seats = 0 次、kg = 0 次；承重（load capacity）全站未见。

品类最会写差评的两件事（耐不耐用、晃不晃），站上一个都没在决策位置正面回答。

⚠️ P1-8 「AS SEEN IN」媒体墙被调到 40% 透明度，10 条引语没有一条署名

logo 容器的 parentElement 计算样式 opacity: 0.4（img 自身 opacity=1、filter=none）；共 11 个 slide，10 张 logo（The Awesomer / Yanko Design / Geeky Gadgets 等），全部 alt=""；10 条引语与 10 个 logo 是两条独立轮播，任一时刻显示的引语与下方 logo 没有对应关系。

为什么严重：媒体引语本身写得很好——"Let you and your friends gather around the grill instead of leaving your grill master off in a corner somewhere." 这句直接命中 VOC 母题。但一条没有出处的引号在转化上价值接近 0。NOMAD 靠 16 条署名媒体引语焊死了"便携 grill"的话语权，AroundFire 有同样的素材，却把它做成了背景装饰。

⚠️ P1-9 移动端吸底条只有价格没有加购按钮，主 ATC 在 1.4 屏之下

viewport 390×844 实测：主 Add to cart 按钮 top = 1163px（首屏之下约 1.4 屏），高 50px；价格 $189.00 USD 位于 y = 583px；滚动到 y=2500 后，唯一可见的 fixed 元素是 <PRODUCT-ADD-TO-CART-STICKY>，内容为 Gather Lite Basic Set $189.00 USD + 一个展开箭头 —— 没有 Add to cart 按钮，必须先点箭头展开。

Meta 账户 55-64 岁女性是 ROAS 最高人群（7.35，即广告花 1 元换回 7.35 元销售额，行业普遍认为 3 以上算健康）、65+ 女性 CPA 最低（$27，约 ¥195；获取一个订单的广告成本）——这两个人群对"多一次点击"最不耐受。

⚠️ P1-10 PDP 首图是"一堆零件"，不是"那顿饭"

Gather Lite PDP 第 1 张主图是白底平铺的开箱件——折叠好的桌架、灰色收纳包、烤网、火网、两根加高杆。生活场景图排在第 5 张之后。

对照：VOC 母题是"解放烤肉的那个人"；社媒盘点 38 条爆款里找不到一条白底产品图；Meta 素材数据里真人 UGC（evcinshome ROAS 7.00、cait 沙滩 6.31、Paige 5.31）全面跑赢自制混剪。

广告把人用"一群人围着桌子吃饭"的画面带进来，落地页第一眼给的是一袋零件。这是投放与落地页之间最直接的一处断档。

结账后仅 33.1% 转化，最可能的流失原因（按可归因强度排序）

  1. 运费的「时机」而不是「金额」（最主要）。$24.90 本身不算离谱，但它出现在用户已经投入 9 个字段的沉没成本之后，且此前全站三处（PDP / 购物车 / 结账初始态）都在给用户 $189 这个锚点。价格锚点被打破 + 无预告 = 典型的结账弃单触发点。

9本方案的边界与待甲方确认项（诚实声明）

  1. 未在目标站注入或测试任何 CSS / 选择器。本次是只读实勘，所有"后台路径"是 Shopify 通用路径与主题设置层面的指引，不含可直接粘贴的选择器——静态 DOM 抓到的节点可能是模板节点而非线上渲染节点（历史教训）。落地时需登录甲方后台逐条实测后再交付代码。
  2. 待甲方提供的数据：桌面承重（load capacity）、Gather Grande 真实座位数、对比表里 69/55/90 lbs 分别对应哪个品牌型号。
  3. 待甲方拍板的政策：$250 免邮门槛（需毛利核算）、火网免费补件政策。
  4. 未测页面速度：本次为中国出口网络，不能归因站点。需甲方跑 PageSpeed Insights / Search Console CrUX 后单独出一份。
  5. 中国 IP 落 Japan / JPY 不是缺陷，是 Shopify Markets 地理定向，本报告所有取证已切到 US/USD。
  6. 未测真实美国 IP 下的首屏：本次靠 ?country=US 切 Shopify Markets，货币与价格已是 USD，但不排除美国 IP 下还有地域化模块差异。
